Einmalig einrichten

Die Preise kommen von Google Maps. Dafür brauchst du einen kostenlosen API-Key. Das dauert etwa 3 Minuten.

  1. 1
    Places API aktivieren Auf «Aktivieren» tippen. Google verlangt dafür eine Zahlungsmethode, das Gratiskontingent reicht für den privaten Gebrauch. Google Cloud öffnen
  2. 2
    API-Key erstellen «Anmeldedaten erstellen» → «API-Schlüssel». Unter «Websites» dieses Muster eintragen und die Einschränkung auf «Places API (New)» setzen:
    Key-Seite öffnen
  3. 3
    Key einfügen
